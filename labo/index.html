Atelier d'animations

Chaque vignette tourne en boucle et se rejoue au clic. Même échelle et même rendu que le jeu : ce qui est choisi ici se transporte tel quel.

Retenues — intégrées au jeu

Le jaillissement suivi d'une secousse pour la bulle, la poussière mêlée aux rayons pour la pose. Ces deux vignettes appellent le code du jeu, pas une copie : ce que tu vois ici est ce qui tourne dans l'usine.
